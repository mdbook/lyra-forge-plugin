# lyra-forge-plugin icons

Pick the file by the size it will show at. The full icon gets noisy below about 64px,
so smaller sizes use simplified drawings of the same lyre.

| Size | File |
|---|---|
| 128px and up | `lyra-forge-plugin.svg` (rounded tile), `lyra-forge-plugin-mark.svg` (no background) |
| 24 to 64px | `lyra-forge-plugin-small.svg` |
| 16px | `favicon-16.svg`, or `favicon.ico` (16, 32 and 48px in one file) |

PNG renders sit beside each SVG, named by pixel size. The mark has see-through cut-outs
and pale highlights, so it reads best on dark or mid-tone backgrounds.

## Colors

- Violet gradient: `#DCC8FF` to `#9364EC`
- Tile background: `#272A35` to `#101217`
- Accent: `#FFC845`
